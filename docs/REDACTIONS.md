# Redactions in the published evidence

Every file below is a published copy of a local evidence file in which only text was replaced: local absolute path prefixes became `<local-scratch>/`, a city name became "a US city", company names became "an operator", SDK version wording became "an earlier SDK", "upgrade" in comments became "feature batch", Chinese text was translated into plain English, and one log had its carriage returns removed. No number and no program logic was changed (line counts are unchanged; numbers on every changed line were compared, the only numbers removed are the version string itself). Where a local path stood unquoted in a shell assignment, the placeholder was put in double quotes so the script still parses (`bash -n`).

Consequence for hashes: the sha256 of a published copy differs from the original. Where another file quotes an original hash (for example `qnx_reg_20261118/abl_full/run.log` quotes registry `708d3cbe7ae62e10`, the sha256 prefix of the original `b4m4_registry.tsv`), the original hash is the one in the fourth column.
