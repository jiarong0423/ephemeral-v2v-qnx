# j23b_sysconn.txt - J23B: reviewed system-service connections of the J23B types ("channel_connect:<types>" ability, the form the QNX 8.0.6
# policy generator writes), appended by scripts/g17_secpol_tool.py merge as part 3 of the combined policy after the learned system types
# (devb_t, random_t, pipe_t from the develop boot evidence/g17/qnx_learn.serial.clean.log). No J23B type needs the pipe manager any more
# (no FIFO); only the harness keeps pipe_t (shell pipes). DRAFT: a "failed to use ability channel_connect" line in the secpol boot, or a learn
# round (J23B_ROUNDS="nopol learn secpol"), decides whether more is needed. Without "nonroot" a grant holds only while the process is root.
